A GitHub-compatible git forge in a single Node process: git smart HTTP v2 (upload-pack / receive-pack, shallow fetch, annotated tags), REST v3 (repositories, branches, commits, contents, issues, labels, pull requests, squash merges), GraphQL v4 (viewer, repository, issues, pull requests, mutations, node ids, cursor pagination) and MCP over streamable HTTP — all over its own in-memory, content-addressed store. No git binary, no database, no outside service; Node 22 standard library only.

## Run it

```sh
node --experimental-strip-types main.ts
```
